# Security

Please report security issues privately. Contact details and the disclosure policy are published at
<https://feralin.com/.well-known/security.txt>.

Do not open a public issue for a vulnerability. Include the affected SDK, its version and steps to reproduce.

Güvenlik açıklarını lütfen herkese açık bir kayıtla değil, yukarıdaki adreste yazan iletişim yoluyla bildirin.
